# Spicetify Visualizer

Custom App `visualizer` do [Konsl/spicetify-visualizer](https://github.com/Konsl/spicetify-visualizer), branch `dist`, instalado em `~/.config/spicetify/CustomApps/visualizer`.

Versão de origem conferida: commit `0b638afc56bdb0ece843c9569ca658a81ade6d53` (2026-10-07). Arquivos sob licença MIT do projeto original; consulte `LICENSE` upstream.

No Spotify use o item Visualizer da barra lateral. O repositório mantém a aplicação customizada junto aos dotfiles para referência e reinstalação. Para atualizar, baixe a branch `dist` upstream e substitua os três arquivos (`index.js`, `manifest.json`, `style.css`), depois execute `spicetify apply`.
