# Créditos e licenças

Este projeto documenta e agrupa preferências pessoais. Os arquivos mantêm cabeçalhos de licença/crédito quando presentes; arquivos de terceiros permanecem sob suas licenças originais.

| Conteúdo | Origem / licença | Observação |
|---|---|---|
| HyDE e módulos do HyDE | [HyDE Project](https://github.com/HyDE-Project/HyDE) | Dependência externa; não incluída aqui. |
| Catppuccin Kitty | [Catppuccin Org](https://github.com/catppuccin/kitty), MIT | O cabeçalho original está em `kitty/bloody.conf`; este tema foi a base das cores do terminal. |
| Tema GTK Bloody-Carmine | [Graphite GTK Theme](https://github.com/vinceliuice/Graphite-gtk-theme) | Tema local derivado. Confira a licença upstream antes de redistribuir o diretório `gtk/`. |
| Tema Kvantum/wallbash | Derivado da configuração wallbash local e Qt/Kvantum | Verifique cabeçalhos e licença do projeto de origem antes de redistribuir. |
| Quickshell | Quickshell, GPL-3.0 | Dependência externa; o projeto fornece o runtime, não o código desta configuração. |
| Spicetify Visualizer | [Konsl/spicetify-visualizer](https://github.com/Konsl/spicetify-visualizer), MIT | Custom app incluído em `spicetify/visualizer/`; veja o README próprio para estado e instalação. |
| Wallpaper do corvo | Arte gerada para este desktop | Incluída no repositório e no showcase. |

Este inventário é informativo, não substitui a leitura das licenças upstream. Consulte e mantenha os avisos de copyright antes de publicar cópias ou derivados.
